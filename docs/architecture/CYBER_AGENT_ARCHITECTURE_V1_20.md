- Decision: ADR-0030; implementation and verification: STATUS

The single Base Contract retains its identity and advances to generation2.
Its bounded guidance distinguishes current supported facts from historical model
recollection for the same target/field/scope, preserves genuine uncertainty,
does not promote Memory or metadata into fresh execution/evidence, and follows
the operator's current response format. Guidance is not enforced factuality.

only path. Existing hashes, audit and Baseline owners observe the new bytes.
Historical exact bytes reconstruct unchanged; current/resumed Turns use current
generation. No new persisted selection/schema, public API, registry, evaluator,
automatic tool use, retry, history rewrite, or remote hash seal.
