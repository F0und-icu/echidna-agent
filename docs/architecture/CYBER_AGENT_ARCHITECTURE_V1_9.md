# Cyber Agent Architecture v1.9 — Readable CLI and Large Context

- Version: 1.9.0
- Status: FROZEN ADDITIVE BASELINE (LOCAL; REMOTE SEAL UNAUTHORIZED)
- Base: immutable v1 through v1.8
- Governing decision: ADR-0019
- Implementation/verification: governed by STATUS.md

Default Tool presentation is a bounded, escaped local projection of execution plans and durable outcomes; it is not a new fact source. Content-focused development debug replaces per-SSE JSON while preserving actual request observation, redaction, decoded reasoning, completion uncertainty and release exclusion. Primary answers are not printed twice.

One ContextPlanner applies versioned capped proportional reserves to explicitly configured model windows, equally for Chat, Compaction and Vision. CapabilityMapping is still the capacity authority; no provider-name inference, general router, automatic compaction or new configuration layer is added. All prior ownership, persistence, Full-only reasoning-continuation and one-AgentLoop invariants remain.
