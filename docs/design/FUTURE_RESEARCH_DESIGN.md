# 随模型能力增长的研究工具

状态：**设计储备，未实现**。记录本次交流的方向，不授权下一 Slice；当前行为以
STATUS 和代码为准。模型更强应首先提升任务理解、证据判断与方法迁移，内核继续
提供可复现的执行与恢复基础。不能把增加自动动作次数作为进步的替代指标。

## 1. 稳定事实边界，允许策略替换

长期保留：原始 Artifact、真实 Receipt、追加式事件、可归属的 Session、明确预算、
工具结果配对、未知副作用与可验证恢复。Prompt、上下文选取、方法说明和工具描述
可以随模型变化用固定样本比较，再决定替换。更强的模型仍不能把 Summary 当证据。

任务从当前请求与仍适用的约束产生；表达目标、范围、停止条件和预算时优先复用
现有输入/Context。Phase 提供方法，不能创造任务。不预设新的任务解释器、计划 DSL
或模型裁判服务。先用任务级评估证明现有表达的缺口，再判断是否需要版本化契约。

## 2. 能够重新研究的项目

让未来模型可从旧项目的原始材料、失败路径、负对照与未解问题继续验证：

- 结论绑定目标版本、输入哈希、环境、方法版本和前提。
- 新模型得到新结论时追加来源与对照，保留原结论及其适用时期。
- “用新模型重审”由操作者明确发起，有独立预算与评价范围。
- 新事实验证当前目标；旧事实不会仅因模型升级自动成为当前证据。

第一步可选一个既有普通工程项目，对相同材料和固定问题手动复评，比较任务质量、
新增真实证据与成本。没有收益就保留原路径，不能依赖自动批量重审扩张范围。

## 3. 逐层展开材料

先提供紧凑目录、摘要与稳定引用，按需回到源码位置、图像、协议字节和运行输出。
所有可展开引用要说明原始材料是否留存、截断范围、所属环境与目标。摘要缺失细节
不能由模型补写。复用现有 Artifact/read_output/RequestAudit；新 UI 只定位和呈现。

测量：重复读取次数、取回正确字节的成功率、任务成功率与总输入成本。更大上下文
不直接等价于更好效果；长窗口、按需读取与压缩需在相同任务上比较。

## 4. 从轨迹提炼可复用方法

先手工选择三次有价值的重复实践，整理成方法说明、脚本/解析器、fixture 和负对照。
每份方法写明适用条件、输入输出、工具依赖、停止条件、失败解释、来源与版本。
模型可提出方法候选，采纳和升级须经回归与证据审查；不自动安装或执行候选。

执行、预算、Session、恢复、Receipt、证据仍由内核统一负责。能力包不能自带第二个
AgentLoop。现有工具不自动发现 SKILL.md，也没有 MCP/热加载/插件 ABI；首个样例
可用显式 Project Prompt 与通用命令工具，后续接口以真实重复需求决定。

## 5. 评价真实任务，而非单一总分

| 场景 | 工程完整性 | 模型质量 |
| --- | --- | --- |
| 旧项目新 Session 问候 | 输入/背景来源正确送达 | 零工具，不自动续做旧目标 |
| 连接检查后停止 | 真工具结果与 Receipt 保留 | 足够证据后结束 |
| 目标替换、歧义“继续” | 新约束按 Turn 生效 | 不跨目标套用结论，必要时澄清 |
| Compaction/Resume | 引用、配对、来源、恢复精确 | 记住目标边界，不误把摘要当新命令 |
| 后台控制 | 取消、租约、未决效果诚实记录 | 正确发现/控制资源，不虚称回收 |
| 验证任务 | 原始证据可复现、负对照完整 | 选择有判别力的最小实验 |

分别记录成功/失败/有限通过、工具次数、重复读取、Token/时间和未覆盖条件。
离线模拟只证明传递和执行链；模型服从性需单独授权、有请求/时间上限的实测。
保留失败样本，避免只展示成功案例。当前模型表现 LIMITED/FAIL 的历史记录不改写。

## 6. 建议的实施顺序

1. 可靠性：现有测试超时诊断；按发送前、响应中、整样本提交后区分网络恢复；
   `/compact` 缺前提时的可解释拒绝；累计预算及真实 usage 的区别。
2. 交互：清楚显示当前任务/目标/Session、运行资源与未知结果，再考虑 TUI。
   主题通过已有事件呈现，不为 UI 创造第二套状态权威。
3. 可复用研究：环境来源（host/container/device）、证据定位、结果交接模板及首个方法样例。
4. 第二个真实消费端出现后，确定 headless 入口、core 提取与外部协调协议。

每项分别确定最小 Slice、真实消费者、测试与必要 ADR。网络重试不授权工具重放；
重试是否安全必须由已观察的提交状态决定，不能凭超时推断服务端未执行。
此文不实现以上能力，也不改变当前单 AgentLoop 和 FullAccess 边界。
