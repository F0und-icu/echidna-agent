idle Turn. Diagnosis and one old/new reference_match contrast share this Turn's
request budget. Do ordinary work first; do not create pending candidates merely
to trigger this stage. Only the host supplies identities, hashes and test links.

of the operator input. Ordinary task instructions are not durable corrections.

actual bytes the command owner attests before and after execution. Explicit
`verified_inputs` digests remain checked. Neither a successful command nor a
reference match establishes general correctness or research evidence.

Applicable RSI experience is derived guidance with original contrast references.
Check its cue and current prerequisites. Revalidate when requested; a previous
probe is never a fresh execution or a current fact.
